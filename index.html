Privacy Policy

Last updated: June 2026

This Privacy Policy describes how TargetWeight (Weight Logger) ("the Application") handles user information. The Application functions strictly as an integration tool to synchronize personal weight data from Garmin Connect to a secure, private database.

1. Information Collection and Use

The Application only processes information that is absolutely necessary to perform its core synchronization service.

  • Garmin Credentials: Your Garmin email and password are submitted via a secure, encrypted HTTPS connection directly to the authentication endpoint. These credentials are used solely to establish an initial connection with Garmin and are never stored permanently on our servers.
  • Authentication Tokens: To maintain an automated data synchronization schedule without requiring you to log in repeatedly, the Application stores an encrypted unique authentication token generated by Garmin. This token is securely kept in our private database (Google Firestore) and is never shared.
  • Weight Metrics: The Application accesses body weight values and timestamps recorded on your Garmin profile to format and process the synchronization.

2. Data Security

We prioritize the security of your data:

  • All communications between the frontend interface, the backend synchronization server, and Garmin's API are fully encrypted using industry-standard Transport Layer Security (HTTPS/TLS).
  • Persistent storage of integration tokens utilizes Google Cloud's protected Firebase infrastructure.

3. Third-Party Sharing

The Application does not sell, trade, rent, or distribute any user information, credentials, or synchronized physical metrics to third-party companies, advertisers, or outside entities. All data processing is strictly functional.

4. User Rights and Data Deletion

You retain absolute control over your integration:

  • You can revoke the Application's access at any time by clearing your configurations or disconnecting the service.
  • If you wish to have your encrypted synchronization token manually purged from the database, you can request immediate removal by contacting the developer.

5. Contact Information

For any questions regarding this privacy statement or to request data removal, please contact:

  • Developer Support: targetweight.app@gmail.com
